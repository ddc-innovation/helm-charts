# 0.1.31 runtime corrections

Live migration of 0.1.30 revealed two defects not caught by schema validation:

1. nindent added a leading blank line to XML ConfigMap content. XML declarations
   must be first. Managed file rendering now trims content and uses indent.
2. Helm removes null values during values coalescing. Root resource definitions
   can therefore omit parent. The reconciler now handles absent parent as a root.

Regression tests parse every rendered plugin XML document and reconcile the
actual Helm-rendered desired.json against the fake API. A separate test removes
root parent keys before reconciliation. All 24 automated tests passed.

This fixes code/configuration defects; it does not reset databases, passwords,
PVCs or existing policies. Resume using the existing site values. Stop an active
waiting Helm process before starting a replacement upgrade. Do not change its
pending release Secret manually or delete application credentials.

The two workers reached Ready during the failed 0.1.30 migration. Coordinator
readiness, corrected live reconciliation, actual worker query execution and HPA
behavior still need acceptance on the corrected release.
